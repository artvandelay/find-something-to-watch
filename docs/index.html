How this works

  • No account or cloud sync. Your settings, profile, and history are written to this browser's local storage and IndexedDB.
  • A disposable Worker executes model-generated catalog code over bundled analytical data. Bounded tool results, your search message, and relevant context go to the model endpoint you configure. Your API key is sent only to that endpoint to authenticate the request.
  • Enabling web search allows OpenRouter/search providers to process relevant queries and results and may add cost.
  • The catalog is a point-in-time snapshot — streaming availability changes constantly, so confirm a title is still where it says before committing to watch it.
  • Clearing this browser's site data removes everything, with no way to recover it. This is not encrypted storage and is not a backup — use “Export backup” in the sidebar for that.
