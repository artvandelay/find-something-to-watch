How this works

  • Stored in this browser. Relevant context is sent to the model endpoint you configure.
  • There is no account, backend, or cloud sync. Files stay local; bounded filenames, structural metadata, and samples can be sent to the configured model endpoint for watch-history layout inference.
  • Availability comes from a dated catalog snapshot and may have changed. Confirm a title at its provider before you watch.
  • Clearing this browser's site data removes everything, with no way to recover it. This is not encrypted storage and is not a backup — use “Export backup” in Settings for that.

Prices are $/1M tokens (input/output). Reasoning badges mean the model can think step-by-step. Model speed is a trade-off you choose: faster models usually answer sooner, but this app cannot guarantee provider queue time or token throughput for an arbitrary bring-your-own-key endpoint.

Bring your preferred compatible model. Model-generated catalog analysis runs in a disposable Worker for fault containment; it is not a hostile-code security sandbox. Enabled web search lets OpenRouter process relevant queries and can add cost.
